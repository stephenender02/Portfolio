Software Engineering and Application Development

My interest in technology started pretty early on, as I would plan out and sketch the latest “inventions” that my seven year old self would come up with. I started learning more about coding and software through a JavaScript animation course on Khan Academy and by toying around with Lua in Roblox Studio. I learned more about the hardware behind computers by building and troubleshooting my own gaming PC, and I was hooked. I knew that I wanted to work with technology when I grew up, and when I learned about the subject of Computer Science, that’s where I set my sights.


Through my university’s CS curriculum, I took a Software Engineering class (CS 345) where I learned about the software development lifecycle, working with a team of developers, working with an AGILE framework, and presenting the final iteration of our product. This class opened my eyes to the joy of collaborative development and thoughtful design before the implementation of a product, as well as how an iterative prototyping based approach to software development can tremendously aid innovation.
